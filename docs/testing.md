# Testing

## Running tests

```bash
make test                # unit tests + race detector
make test-integration    # integration tests (requires postgres + valkey running)
make cover               # unit tests + per-package coverage summary
make cover-html          # generates and opens HTML report
make cover-check         # fails CI if total coverage < 70%
```

Coverage reports are written to `.coverage/` (gitignored).

## Test structure

```
internal/
  core/service/
    publish_test.go          ← unit (table-driven, uses GoMock)
  adapter/inbound/http/
    handler_test.go          ← unit (httptest + GoMock)
  adapter/outbound/postgres/
    repository_integration_test.go   ← integration (real DB)
```

## Unit test conventions

Tests live in `*_test.go` files adjacent to the source. Always table-driven:

```go
func TestPublishDraft(t *testing.T) {
    tests := []struct {
        name    string
        // inputs and expected outputs
        wantErr error
    }{
        {name: "happy path", ...},
        {name: "draft not found", wantErr: domain.ErrNotFound},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            // arrange: build mocks via GoMock
            // act
            // assert
        })
    }
}
```

## Integration tests

Tagged with `//go:build integration` so they are excluded from `make test`. They require live PostgreSQL and Valkey (start with `make docker-up`).

```go
//go:build integration

package postgres_test

func TestWorkflowRepository_Create(t *testing.T) { ... }
```

## Mock generation

Mocks for all `core/port` interfaces are generated by GoMock:

```bash
make mock
# writes to internal/core/port/mocks/ (gitignored)
```

Import in tests:

```go
import "github.com/BCBP-SOLUTIONS-FZC-LLC/workflow-definition-service/internal/core/port/mocks"

ctrl := gomock.NewController(t)
repo := mocks.NewMockWorkflowRepository(ctrl)
repo.EXPECT().GetByID(gomock.Any(), tenantID, workflowID).Return(wf, nil)
```
